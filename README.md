# Smoke Cloud Guy

An interaction prototype: the cursor is a cigarette with googly eyes, and its body is the cloud of smoke trailing behind it.

- Move the pointer and the smoke body follows, leaving puffs behind.
- Click (with the lit tip) and the cigarette goes out, drops to the floor, and the page goes dark. Only the eyes remain, and nothing can be clicked.
- Scroll (wheel, trackpad, or swipe on touch; Space or arrow keys also work) to strike the lighter. A few strikes light a new cigarette and the page comes back.

Everything is in `index.html` with no build step and no assets. Sounds are synthesised with Web Audio. Open the file in a browser to try it.
